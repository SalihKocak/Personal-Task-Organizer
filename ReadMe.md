# To-Do List App

## Description
The To-Do List App is a web application that helps users manage their tasks. Users can add, edit, and delete tasks. Additionally, users can create accounts and log in.

## Features
- User registration and login
- Add, edit, and delete tasks
- Update task status
- User profile and avatar creation

## Technologies
- ASP.NET Core
- MongoDB
- C#
- HTML/CSS

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/username/To-do-list-app.git
   ```
2. Install the required dependencies:
   ```bash
   dotnet restore
   ```
3. Start the application:
   ```bash
   dotnet run
   ```

## Usage
- After starting the application, go to `http://localhost:5000` in your browser.
- Register or log in with an existing account.
- Add, edit, or delete your tasks.

# To-Do List App

## Açıklama
To-Do List App, kullanıcıların görevlerini yönetmelerine yardımcı olan bir web uygulamasıdır. Kullanıcılar, görev ekleyebilir, düzenleyebilir ve silebilir. Ayrıca, kullanıcılar hesap oluşturabilir ve giriş yapabilir.

## Features
- Kullanıcı kaydı ve oturum açma
- Görev ekleme, düzenleme ve silme
- Görevlerin durumunu güncelleme
- Kullanıcı profili ve avatar oluşturma

## Teknolojiler
- ASP.NET Core
- MongoDB
- C#
- HTML/CSS

## Kurulum
1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/kullaniciadi/To-do-list-app.git
   ```
2. Gerekli bağımlılıkları yükleyin:
   ```bash
   dotnet restore
   ```
3. Uygulamayı başlatın:
   ```bash
   dotnet run
   ```

## Kullanım
- Uygulamayı başlattıktan sonra tarayıcınızda `http://localhost:5000` adresine gidin.
- Kayıt olun veya mevcut bir hesapla giriş yapın.
- Görevlerinizi ekleyin, düzenleyin veya silin.
